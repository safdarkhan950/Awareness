# Assets Directory

This folder contains the core processing engines and static assets that power the Awareness OS front-end interface.

## Subdirectory Mapping
* `js/` - Core application scripts.
* `js/app.js` - Main client bootstrapper and page lifecycle manager.
* `js/components/` - Isolated visual render engines mapped by individual life workbook dimensions (Wellness, Budget, Investments, Dividends).

## Usage Note
Do not place user configurations or raw spreadsheet data in this folder. It is designed to host static application code only.
